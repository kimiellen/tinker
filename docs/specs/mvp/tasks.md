# tinker MVP 任务清单

事实源：[spec.md](spec.md) · UI 定稿：[ui-mockup.html](ui-mockup.html)（2026-10-21 用户确认）

## M1：项目骨架 + 音频内录

- [ ] uv 初始化 FastAPI 后端项目，托管 `frontend/` 静态文件
- [ ] 录音服务：PipeWire/PulseAudio monitor 内录系统输出，start/stop API，保存 wav 到 `data/recordings/`
- [ ] 录音列表 API + 音频文件访问
- [ ] 前端：歌曲库界面（按 UI 定稿 ①②），录新歌 → 录音中状态 → 完成入列表 → 浏览器内回放
- [ ] **验证**：启动服务，实际录一段系统播放的音频，前端列表出现且可回放

## M2：歌词逐句对齐 + 逐句学习

- [ ] 歌词文本导入（粘贴）并与歌曲关联
- [ ] faster-whisper 词级时间戳转写 + 歌词匹配，产出逐句时间区间
- [ ] 逐句播放 API（按时间区间切片/定位播放）
- [ ] 前端学习界面（按 UI 定稿 ③）：逐句显示、点击单句播放、单句循环、0.5x/0.75x/1x 变速
- [ ] **验证**：一首真实歌曲完成逐句切分，前端单句可循环变速播放，切分人工抽查准确

## M3：逐句翻译 + 连读/吞音标注

- [ ] LLM 客户端（可配置 API，默认 DeepSeek），结果落盘缓存，重复请求不调 API
- [ ] 逐句中文翻译
- [ ] 按英语发音规则的连读/吞音标注（文本规则标注，不做音频实测）
- [ ] 前端：翻译展示 + 标注高亮（按 UI 定稿 ③ 的连读/吞音样式）
- [ ] **验证**：一首歌翻译与标注正确展示；二次加载无 API 调用（查缓存）

## M4：跟唱评估

- [ ] 跟唱录音（单句/整首）API
- [ ] librosa 音高提取：原唱 vs 跟唱，时间对齐
- [ ] 逐句评估：调偏高/偏低、抢拍/拖拍，产出明确到句的文字反馈
- [ ] 前端评估界面（按 UI 定稿 ④）：音高曲线叠加 canvas + 逐句反馈卡
- [ ] **验证**：故意唱跑调一句，评估结果能指出该句问题
