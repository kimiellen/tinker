# tinker MVP 任务清单

事实源：[spec.md](spec.md) · UI 定稿：[ui-mockup.html](ui-mockup.html)（2026-10-21 用户确认）

## M1：项目骨架 + 音频内录 ✅（2026-10-21 完成）

- [x] uv 初始化 FastAPI 后端项目，托管 `frontend/` 静态文件
- [x] 录音服务：PipeWire/PulseAudio monitor 内录系统输出，start/stop API，保存 wav 到 `data/recordings/`
- [x] 录音列表 API + 音频文件访问
- [x] 前端：歌曲库界面（按 UI 定稿 ①②），录新歌 → 录音中状态 → 完成入列表 → 浏览器内回放
- [x] **验证**：启动服务，实际录一段系统播放的音频，前端列表出现且可回放
  - 证据：播放 440Hz 测试音同时内录，录得文件主频 ≈434Hz、时长与播放一致、无残留进程；丢弃路径、400/404 错误路径均验证通过

## M2：歌词逐句对齐 + 逐句学习 ✅（2026-10-21 完成）

- [x] 歌词文本导入（粘贴）并与歌曲关联
- [x] faster-whisper 词级时间戳转写 + 歌词匹配，产出逐句时间区间
- [x] 逐句播放 API（按时间区间切片/定位播放）
- [x] 前端学习界面（按 UI 定稿 ③）：逐句显示、点击单句播放、单句循环、0.5x/0.75x/1x 变速
- [x] **验证**：一首真实歌曲完成逐句切分，前端单句可循环变速播放，切分人工抽查准确
  - 证据：CC0 歌曲《Twinkle Twinkle Little Star》全歌词版（125.7s）对齐出 27 句、覆盖 0–124.7s 单调无重叠；抽取第 5/13/22/27 句切片单独转写，内容与歌词一致（4/4）；aligner 单元测试 7 项通过；API 错误路径（400 无歌词 / 409 分句中 / 404 / 422 空歌词）与音频 Range（206）均验证通过
  - 实现备注：faster-whisper 1.2.x 的 PyAV 解码与 av≥15 不兼容（旧版无 py3.14 wheel），改用系统 ffmpeg 解码为 16k 单声道喂给模型
