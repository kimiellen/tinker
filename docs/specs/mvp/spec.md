# tinker —— 英文歌学唱应用 spec

## 目标

帮助小学生（首要用户：一年级女孩）及成人通过英文歌学唱。核心闭环：

1. **内录**：浏览器播放网页版网易云音乐 → PipeWire monitor 录制系统输出为本地音频文件
2. **逐句学习**：歌词逐句对齐（时间戳）、逐句翻译、连读/吞音等歌唱技巧标注；单句点播/循环/变速

（2026-10-24 spec-change：原第 3 条「跟唱评估」整体移除——用户决定学习页不需要「我唱一遍」跟唱与评估反馈。学习页按钮、评估页、后端 attempts API、evaluator、librosa/python-multipart 依赖一并删除，代码可从 git 历史找回。）

## 用户与场景

- 首要用户：小学一年级女孩，运行在家长的 Arch Linux 机器上，浏览器打开使用
- 界面要求：高度自定义（不使用任何现成 harness/框架的默认 UI）、对儿童友好（大字体、少文字、强可视化）

## 关键约束

- 单机单平台：仅 Arch Linux，**无跨操作系统分发需求**
- 音源固定：网页版网易云音乐在浏览器中播放，应用只负责录系统输出，不与网易云做任何 API 集成
- 全部功能本地运行，**无任何外部 API 依赖**（2026-10-21 spec-change：翻译曾走 LLM，但其唯一用途就是逐句翻译——用户导入歌词时直接中英混贴即可，LLM 接入整体移除）

## 选定方案及理由

**形态：独立本地应用** —— Python/FastAPI 后端 + 无构建步骤的原生 HTML/JS/CSS 前端（后端直接托管静态文件，浏览器打开）。

否决项：
- **dsh 插件**：dsh 插件系统是 cordis 体系的 harness 自身扩展机制（面向 agent 能力与 dsh web GUI 内嵌 UI），不是面向最终用户的应用分发平台；且 UI 受插件容器约束，与"高度自定义界面"冲突。
- **浏览器扩展**：无法承担本地音频分析、AI 推理与文件管理；Linux 下 PipeWire 已可直接录系统输出，扩展无增量价值。

**关键技术选型**：
- 录音：PipeWire/PulseAudio monitor source（`pw-record` / `parec`）
- 歌词对齐：faster-whisper（词级时间戳）与歌词文本匹配，得到逐句时间戳（2026-10-23 spec-change：切边前先把相邻两句锚词之间"无人认领"的转写词按两侧歌词缺失词数分配归属——歌词首词被转写变形（如 Forecaster→forecasters）导致匹配失败时，旧逻辑会把该词切给上一句，用户听到"下句的词出现在上句"）
- 歌词导入：**中英混贴**，含中文的行自动识别为上一英文句的翻译（2026-10-21 spec-change，替代 LLM 翻译——粘贴即得，零成本零延迟；多/少贴不报错，缺译留空）
- 逐句播放：**整文件连播 + 时间戳高亮**，不做音频切片（2026-10-21 spec-change）。句区间已按换气口能量低谷切分且句间无缝；旧方案每句结尾回退 seek 接下一句，因 timeupdate 约 0.25s 延迟把下一句开头重播一遍（用户反馈"句首/句尾重复发音"）。连播零 seek 从根上消除重复，高亮按 currentTime 落在哪句区间就亮哪句。起播/重播从 0 开始，**保留前奏**（同日追加）；点句/下一句仍是显式跳句首
- 连读/吞音标注：**本地规则引擎**（发音词典查首尾音素，按英语发音规则推断）。曾用 LLM 按规则预标注，实测准确率仅三四成且大量漏标——LLM 不做音素级推理，模式匹配不可靠（2026-10-21 spec-change）；规则是确定性的，本地实现准确、可测、零成本。仍不做音频实测——实测不可靠，规则标注教学上够用
- 翻译：随歌词一起粘贴导入，不调用任何外部服务
- Python 依赖管理：uv

## 功能范围（MVP）

- 音频内录与管理（录制、列表、回放、删除）
- 歌单删除与排序：列表项的删除按钮带二次确认（2026-10-23 spec-change：替换首页播放按钮——学习页已有完整播放能力，列表页播放冗余；删除是破坏操作必须确认）；拖动排序持久化到后端，新录的歌排在最前
- 歌词导入（中英混贴粘贴）与逐句自动对齐
- 逐句学习界面：整首连播、当前句高亮跟随；单句循环开关、上一句/下一句跳转、变速（0.5x/0.75x/1x）
- 逐句中文翻译、连读/吞音标注展示；标注可逐句手动修正（2026-10-23 spec-change：数据模型改为每句只存 `-`/`^` 标记文本，废弃 liaison/swallow 结构化字段，见 docs/specs/edit-markup/spec.md）

## 非目标（明确不做）

- 跨操作系统分发 / Windows / macOS 支持
- 歌词点词查词、生词本、闪卡复习等英语学习功能（后续再议）
- 星星/积分等游戏化奖励机制
- 与网易云音乐的 API 集成、自动抓歌词
- 从音频实测歌手的连读/吞音
- 简单的百分制打分
- 跟唱录音与评估（2026-10-24 spec-change：原 M4 功能整体移除，明确不再做）
