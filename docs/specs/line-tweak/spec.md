# line-tweak —— 逐句手动微调句界 spec

## 目标

自动分句后个别句界仍不准（whisper 词级时间戳在句界处系统性偏晚 0.3~0.5s，
词内辅音停顿与换气口声学上无法区分，全自动修边已实验证明到天花板——
2026-10-23 两轮对照实验：宽窗口能量法会误切词内 /k//p/ 爆破间隙，onset 法会
误切词内音节起音）。提供人工兜底：学习页每句卡片右侧竖排两个小按钮，
点一下把句界向该方向吸附到下一个能量低谷（换气口），邻句自动同步收缩。
使用人是家长（帮孩子修），不是孩子本人。

## 选定方案及理由

- **粒度：逐换气口（时间微调 + 低谷吸附），而非逐词**（2026-10-23 用户确认）。
  整词错归属已被 aligner 的词归属分配修复；剩余误差是亚词级（whisper 词戳
  偏晚），逐词按钮对它无解；低谷吸附一次点击到位（实测 26.90→26.61）。
- **两个按钮都是"扩充"语义**：上按钮 = 句首向前扩（上句同步变短），下按钮 =
  句尾向后扩（下句同步变短）。反向收回用邻句的同向按钮实现，无需第三种交互。
- **吸附算法**：从当前句界沿方向 0.8s 窗口内取 RMS 能量最低点（25ms 窗/10ms
  步长，与 aligner 换气口切边同一套包络）。人工监督下不需要复杂度——点一下
  听一下，不对就再点或反向点。
- **钳制**：句界不得越过邻句使邻句不足 0.3s；共享句界（prev.end==cur.start）
  两句同步移动，间奏分隔的句界只动本句、不吞噬间奏另一侧。
- 只改 start/end 时间戳；歌词文本、标注、翻译不受影响；跟唱评估消费同一
  lines，自动跟随新句界。

## 界面

- 句卡底部行右侧、「✏️ 修改标注」按钮之右：竖排两个小幽灵按钮，
  上「◀」（句首往前扩）下「▶」（句尾往后扩），title 提示完整语义。
- 点击静默生效（句卡只显示文本，时间不可见），失败（到头了/未分句）按钮
  短暂显示 ✕。
- 不触发句卡的点句播放（stopPropagation）。

## 非目标

- 不做撤销（反向点击即撤销）
- 不做拖动句界、不做波形可视化编辑
- 不对存量歌曲做数据迁移（本功能不依赖词级数据，旧分句结果直接可用）
